# AGENTS.md — Shoyisty («Галя Балувана»)

> **Спершу прочитай [PROJECT-CONTEXT.md](PROJECT-CONTEXT.md).** Там зафіксовано архітектурні інваріанти, модель даних, префікси сховища та матрицю перевірок якості. Цей файл — практична витримка для щоденної роботи автономних агентів.

---

## 1. Домен та призначення

Мобільний PWA веб-застосунок **«Шпаргалка меню на тиждень»** для мережі домашніх напівфабрикатів ручної ліпки «Галя Балувана» в Одесі та м. Південне.

- **Ціль**: швидкий вибір страв на 7 днів (3 прийоми їжі) або вибір одного з 4 готових збалансованих наборів, та автогенерація подвійного списку покупок («Галя Балувана» + супермаркет) з експортом у Telegram/Viber.
- **Стек**: SvelteKit 3 + Svelte 5 (виключно Runes), TypeScript 6, `@sveltejs/adapter-static`, CSS Variables.
- **Хостинг**: GitHub Pages (`https://tetianafominaua.github.io/shoyisty/`).

---

## 2. Ключові інваріанти коду

1. **Svelte 5 Runes**: Жодного Svelte 4 API (`export let`, `$:`, `<slot>`). Використовувати тільки `$state`, `$derived`, `$props`, snippets.
2. **Імпорти модулів**: Виключно Node/SvelteKit subpath-імпорти `#lib/*` (заборонено застаріле `$lib/*`).
3. **Ізоляція сховища**: Префікс ключів виключно `galya_planner_*`. Усі операції з `localStorage` огортаються в `try-catch`.
4. **Безпека XSS**: Заборона несанітизованого сирого `{@html}`. Контролюється тестом `src/security.test.ts`.
5. **Обробка помилок**: `<svelte:boundary>` з `ErrorFallback.svelte` та клієнтський захист від застарілих чанків у `src/hooks.client.ts`.

## 4. НЕ РОБИ

- **НЕ** використовуй `$lib/*` замість `#lib/*`.
- **НЕ** ламай структуру `localStorage` ключа `galya_planner_week_v1`.
- **НЕ** підключай важкі сторонні UI бібліотеки — використовуй Vanilla CSS токени у `src/app.css`.
- **НЕ** коміть код без виконання `npm run check && npm test && npm run build`.

## Проєкт «Шпаргалка меню на тиждень» («Галя Балувана»)

### Головні правила розробки:

1. **Канон:** Єдине джерело архітектурної правди — `PROJECT-CONTEXT.md`. Завжди звіряйся з ним перед внесенням змін.
2. **Імпорти:** Використовувати субпатч-імпорти `#lib/*` (замість застарілого `$lib/*`).
3. **Реактивність:** Svelte 5 з рунами (`$state`, `$derived`, `$props`). Не використовувати застарілі Svelte 4 стори (`writable`).
4. **Контроль якості:** Кожен коміт повинен успішно проходити:
   ```bash
   npm run check
   npm run lint
   npm test
   npm run build
   ```
5. **Сховище:** Не ламати сумісність ключів `localStorage` (префікс `galya_`).

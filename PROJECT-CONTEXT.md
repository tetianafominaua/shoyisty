## 1. Загальні відомості та бізнес-місія

- **Продукт:** Веб-додаток «Шпаргалка меню на кожен день» (Mobile-first PWA).
- **Цільова аудиторія:** Мешканці Одеси та м. Південне, які хочуть позбутися щоденного головного болю «Що сьогодні приготувати?», економити 4–5 годин на кухні щотижня та отримувати готовий збалансований список покупок.
- **Особливості асортименту:** Домашні напівфабрикати ручної ліпки за склом мережі «Галя Балувана» (4 локації в Одесі та Південному):
  1. _Одеса, вул. Сегедська, 6_ — головне виробництво за склом (пельмені, вареники, сирники, млинці, готова кулінарія).
  2. _Одеса, вул. Ак. Корольова, 53_ — фірмовий магазин.
  3. _Одеса, вул. Св. Ріхтера, 129а_ — фірмовий магазин.
  4. _м. Південне, вул. Шевченка, 18/6_ — виробництво з кам’яною піччю (піца, хачапурі, гриль-меню).

## 3. Реєстр префіксів сховища (STORAGE-NAMESPACE-v10 § 1)

Сайт використовує суворо ізольовані префіксовані ключі у `localStorage`. Усі операції читання та запису загорнуті в `try-catch` блоки для захисту від блокування cookies або переповнення квоти.

- **Префікс сховища**: `galya_`

### Реєстр ключів сховища:

| Ключ                              | Призначення                                               | Тип даних                  |
| :-------------------------------- | :-------------------------------------------------------- | :------------------------- |
| `galya_planner_week_v1`           | Збережене тижневе меню користувача (Пн–Нд, 3 прийоми їжі) | `Record<DayKey, DayMeals>` |
| `galya_planner_set_v1`            | ID активного готового набору (якщо завантажено)           | `string`                   |
| `galya_planner_checked_v1`        | Стан викреслених чекбоксів у списку покупок               | `Record<string, boolean>`  |
| `galya_planner_family_v1`         | Обраний розмір родини для розрахунку порцій (1..5)        | `1 \| 2 \| 3 \| 4 \| 5`    |
| `galya_planner_pack_overrides_v1` | Ручні коригування кількості упаковок у кошику             | `Record<string, number>`   |

## 4. Архітектура даних та алгоритми розрахунку

### 4.1 Модель даних

1. **Страва (`Dish` у `src/lib/types.ts`):** містить час приготування, ккал, кількість порцій на упаковку, зв'язок з фірмовим товаром `galyaProduct` та перелік інгредієнтів для супермаркету `groceryItems`.
2. **Готові набори (`ReadyMadeSet` у `src/lib/data/sets.ts`):** 4 кураторські раціони («Сімейний затишок», «Експрес / Для зайнятих», «Дитяче / Мамине меню», «Гурман / Гастро-вихідні»).
3. **Розрахунок кошика (`calculatePlanCart`):**
   - Автоматично множить потребу у порціях на коефіцієнт розміру родини (`familySize / servingsPerPack`).
   - Округлює кількість упаковок у більшу сторону (`Math.ceil`).
   - Супутні продукти агрегує без повторів: грами конвертує в кілограми при $\ge 1000$ г, мілілітри — у літри, для штук використовує правильні форми множини (`1 пачка`, `2 пачки`, `5 пачок`).
4. **Масштабованість та експорт (`src/lib/services/backup.ts`):**
   - Дозволяє експортувати поточне меню та список покупок у JSON-файл та імпортувати його на будь-якому іншому пристрої без потреби в хмарній реєстрації.

## 5. Обробка помилок та Error Boundaries (ERROR-HANDLING-v10)

- **Межа помилок Svelte 5 (`<svelte:boundary>`)**: Усі компоненти сторінки в `src/routes/+layout.svelte` огорнуті в `<svelte:boundary>`. У разі збою рендерингу відображається `ErrorFallback.svelte`.
- **Захист від застарілих чанків (`hooks.client.ts`)**: При виявленні клієнтських помилок завантаження модулів після нового релізу здійснюється одноразове автоматичне оновлення сторінки (`sessionStorage.getItem('shoyisty_chunk_reload')`).
- **Сторінка 404 / помилок (`src/routes/+error.svelte`)**: Фірмовий екран зі збереженням тем і навігацією повернення на головну сторінку.

## 6. Безпека (SECURITY-v10 & CSP-v10)

- **Content-Security-Policy (CSP) sha256**: У `vite.config.ts` налаштовано режим `mode: 'hash'`, що блокує несанкціоновані зовнішні скрипти, підключення та форми (`form-action: none`, `base-uri: self`, `frame-ancestors: none`). Інваріант контролюється тестом `src/csp.test.ts`.
- **Безпечна санітизація Schema.org (`jsonLdScript`)**: Екранування символів `<`, `>`, `&` та Unicode-розділювачів у `src/lib/security/jsonLd.ts` запобігає XSS-атакам через JSON-LD розмітку.
- **Заборона сирого `{@html}`**: Заборонено небезпечне рендерення без санітизації. Контролюється автоматичним тестом `src/security.test.ts`.
- **Ізоляція ключів сховища**: Сувора перевірка простору імен `galya_` для запобігання конфліктам на спільному origin.
- **Аудит залежностей**: Регулярний CI-скрипт `npm run audit:ci` перевіряє дерево npm-залежностей на наявність відомих вразливостей.

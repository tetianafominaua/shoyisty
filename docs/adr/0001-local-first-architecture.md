# ADR 0001: Local-First реактивна архітектура планувальника меню

## Статус

Прийнято

## Контекст

Веб-додаток «Шпаргалка меню на кожен день» для клієнтів мережі «Галя Балувана» в Одесі та Південному створений для використання на смартфонах безпосередньо в магазині або вдома. Додаток повинен працювати миттєво, офлайн або при слабкому мобільному зв'язку, без обов'язкової реєстрації чи централізованої бази даних.

## Рішення

1. Використовувати Local-First архітектуру на базі `localStorage` із суворим ізольованим префіксом ключів `galya_planner_*`.
2. Реалізувати реактивне ядро через клас `PlannerStore` за допомогою Svelte 5 Runes (`$state`, `$derived`).
3. Забезпечити захист від квот та приватного режиму через безпечні try-catch операції.
4. Розгортати як статичний PWA на GitHub Pages із fallback `404.html`.

## Наслідки

- **Плюси:** Миттєвий відгук інтерфейсу (0 мс затримки мережі), повна приватність користувача, збереження стану при перезавантаженні сторінки, нульові витрати на бекенд-інфраструктуру.
- **Мінуси:** Відсутність автоматичної міжпристроєвої синхронізації (вирішується кнопкою експорту списку покупок у Telegram/Viber).
